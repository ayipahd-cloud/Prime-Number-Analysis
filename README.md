# Prime Number Analysis
A beginner Python application for checking prime numbers and generating prime number statistics.


## Features
- Simple menu-driven interface
- Check whether a number is prime
- Generate all prime numbers up to a chosen number
- Display:
  - Total number of primes found
  - Largest prime number
  - Smallest prime number
  - Complete list of primes


## Example
1. Check if a number is a prime number.
2. Generate a list of prime numbers up to a certain number.
3. Exit.
